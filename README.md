# Last Text at One Percent

Entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) bounty on [make.fun](https://make.fun).

`main.ts` writes one text message — the funniest final text a dying phone
sends at one percent battery, in the phone's own voice — to
`/output/entry.txt`, then verifies the file by reading it back and printing
its SHA-256.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
